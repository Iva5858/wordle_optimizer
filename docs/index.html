    04 / method

    How it works

    For a set of possible answers S, a guess g costs one guess per answer, plus whatever each color group it leaves needs next. The solver minimizes that over the whole tree.

    cost(S, g) = |S| + Σ cost(B)    for each color group B that g doesn't solve
    • Branch and bound over an AND-OR tree. Minimum over guesses, sum over color patterns. Each subset of answers is solved once and memoized.
    • Pruning. A group of n answers needs at least 2n − 1 guesses, so a guess is dropped as soon as it can't beat the best one found.
    • Beam. Guesses are tried in order of how small the groups they leave are. An exact mode tries all of them, which proves the minimum.
    • Speed. Feedback for every guess against every answer is precomputed with numpy, and the subtrees under the opener run on every core.

    The minimum of 7,920 was proven by Bertsimas & Paskov, An Exact Solution to Wordle (Operations Research, 2025).
